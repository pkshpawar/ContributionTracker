# Contribution Tracker (Android)
Compact Kotlin + Jetpack Compose app to track group contributions and expenses.

**Features:** Contribution title, member entry, memberwise collection, expense entry (member, date, 10 categories, payment mode, description, amount), per-member expense total, category-wise tally report, PDF export, Excel-compatible CSV export, JSON backup (export & import), exit button. Footer: `@Prakash Pawar 1.0`.

**Build:** open this folder in Android Studio (Koala+), let Gradle sync, then Run. Data is stored locally on the device.
